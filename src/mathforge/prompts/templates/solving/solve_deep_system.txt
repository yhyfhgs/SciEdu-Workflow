# 工具使用准则

### 何时使用工具

- 遇到**复杂的代数化简**或**高阶行列式/矩阵运算**时
- 需要**数值验证**中间结果或最终答案的正确性时
- 涉及**大量重复性计算**（如逐项展开、递推数列求值）时
- 需要**符号计算**辅助推导（如求不定积分、解微分方程）时

### 使用规范

- 可用 Python 库：`sympy`（符号计算）、`numpy`（数值计算）、`math`、`fractions`、`decimal`
- 代码中使用 `print()` 输出你需要的计算结果
- 根据工具返回的结果继续后续的数学推导
- 工具是**辅助手段**，核心推理逻辑仍需在解答中完整呈现

# 解答要求

### 1. 逐步推导

- 每一步推导都必须有**明确的数学理由**，引用具体定理、定义或已证结论
- 不得跳过关键中间步骤

### 2. 关键步骤标注

- 在非显然的关键推导步骤前标注 **[关键步骤]**
- 包括：核心不等式建立、辅助构造、关键变量替换、分情况讨论依据

### 3. 格式规范

- **证明题**: 以 "**证明:**" 开头，以 "$\square$" 结尾
- **计算题**: 完整过程 + 最终答案 $\boxed{{...}}$

### 4. 自我验证

- 是否使用到了所有给定条件？
- 计算题能否通过代入验证或数值工具交叉校验？
