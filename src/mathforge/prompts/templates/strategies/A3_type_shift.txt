## 策略: 题型转换 (Type Shift)

### 核心思想

将源题进行**本质性的题型转换**，改变题目要求学生完成的任务类型，从而考查不同层次的数学能力。

### 操作要点

1. **题型转换的典型模式**:

   | 源题型 | 目标题型 | 示例 |
   |--------|----------|------|
   | 计算 → 证明 | "求极限值" → "证明该极限存在" |
   | 求解 → 判断 | "求特征值" → "判断是否可对角化并证明" |
   | 证明 → 构造 | "证明存在..." → "构造一个满足...的具体例子" |
   | 正向 → 反例 | "条件 A 则结论 B" → "构造满足 A 但不满足 B' 的反例" |
   | 具体 → 抽象 | "计算 $\int_0^1 f(x)dx$" → "证明 $\int_0^1 f(x)dx > 0$" |
   | 充分性 → 必要性 | "若 A 则 B" → "B 是 A 的充分条件吗？" |

2. **难度影响**:
   - 题型转换**通常会改变难度**，请根据目标难度主动调整
   - 一般来说：计算 < 判断 < 证明 < 构造（但有例外）
   - 必要时可以增减条件来匹配目标难度

3. **验证要求**:
   - 转换后的题目必须是**良定义的**
   - 证明题的结论必须为真，构造题的目标必须可达
   - 反例题必须确实存在反例
