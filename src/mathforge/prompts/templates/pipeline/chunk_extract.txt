## 任务 1：语义截断点
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

分析当前内容，结合后续内容开头，判断当前内容末尾是否处于某个数学对象（定理、证明、定义、例题、解答等）的中间。

**`truncation_line` 取值**：
- **正整数 N**（行号）：第 1~N 行语义完整，第 N+1 行起属于下一个块
- **`null`**：整个当前内容都完整
- **`"incomplete"`**：整个内容都不完整（属于一个未结束的大对象），需追加更多内容

识别当前内容所属的文档层级（章、节、小节），输出到 `structural_context`。如果内容中出现了章节标题变化，使用**最后出现的**章节信息。

## 任务 3：条目直接提取
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

仅从截断点之前的**语义完整部分**中，提取所有数学条目。

### 应提取的条目类型
- 知识性：定义(definition)、定理(theorem)、引理(lemma)、推论(corollary)、命题(proposition)、性质(property)、公式(formula)
- 练习性：例题(example)、练习(exercise)、习题(problem)
- 这些条目如果紧跟证明(proof)或解答(solution)，将其作为 `paired_with` 内容一起提取

### 不应提取为条目的内容
- 章节标题、目录、前言、序言（记录在 structural_context 中）
- 纯过渡性段落（"本章讨论..."、"下面介绍..."）
- 页眉、页脚、页码
- 注记(remark)和纯文字说明段落

### 提取要求
- `content` 必须包含条目的**完整原文**（保留 LaTeX 公式、段落结构）
- 如果条目后紧跟证明或解答，将其放入 `paired_with`
- `line_start` 和 `line_end` 使用当前内容中的行号
- 每个条目必须是一个完整的数学对象，不要截断

## 输出格式
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

严格按以下 JSON 格式输出（**不要**用 markdown 代码块包裹）：

{{
  "truncation_line": null,
  "structural_context": {{
    "chapter_title": "",
    "chapter_number": "",
    "section_title": "",
    "section_number": "",
    "subsection_title": "",
    "subsection_number": "",
    "document_type": "textbook"
  }},
  "extracted_items": [
    {{
      "item_type": "theorem",
      "number": "3.2.1",
      "title": "Heine 定理",
      "content": "设 $f$ 在闭区间 $[a,b]$ 上连续，则 $f$ 在 $[a,b]$ 上一致连续。",
      "paired_with": {{
        "type": "proof",
        "content": "由 Borel 有限覆盖定理..."
      }},
      "line_start": 15,
      "line_end": 42
    }}
  ]
}}

注意：
- 如果没有配对内容，`paired_with` 为 `null`
- `extracted_items` 可以为空数组（当内容中没有可提取的数学条目时）
- 当 `truncation_line` 为 `"incomplete"` 时，`extracted_items` 应为空数组
