## 任务 1：语义截断点
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

分析当前内容，结合后续内容开头，判断当前内容末尾是否被截断。

**截断判定**：如果后续内容的开头是当前末尾未完成对象的延续（证明未完、定理条件未列完、句子被截断），则当前末尾被截断。此时找到当前内容中**最后一个语义完整边界**的行号。

**`truncation_line` 取值**：
- **正整数 N**：第 1~N 行语义完整，第 N+1 行起属于下一个块
- **`null`**：整个当前内容都完整
- **`"incomplete"`**：整个内容都不完整（一个跨多页的大对象），需追加更多内容

## 任务 3：条目提取（核心任务）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

仅从截断点之前的**语义完整部分**中提取条目。

### 条目分类与提取规则

**知识条目**（存入知识点表）：
- 定义(definition)、定理(theorem)、引理(lemma)、推论(corollary)、命题(proposition)、性质(property)、公式(formula)

**论证条目**（存入知识点表，但作为独立条目）：
- 证明(proof) — 必须独立提取，通过 `parent_ref` 指向其所证明的定理/引理/命题
- 注意：证明是定理的**配套条目**，不是定理的一部分。一个定理和它的证明是**两个独立条目**

**题目条目**（存入题目表）：
- 例题(example)、练习(exercise)、习题(problem)、选择题(choice)、填空题(fill_blank)、判断题(true_false)

**解答条目**（存入解答表，关联题目）：
- 解答(solution)、解(answer) — 必须独立提取，通过 `parent_ref` 指向其所解答的题目
- 注意：解答是题目的**配套条目**，不是题目的一部分。一道题和它的解答是**两个独立条目**

### 关键原则：定理与证明分离、题目与解答分离

**正确示例**：
```
原文：
  定理 3.1 (Bolzano-Weierstrass) 有界数列必有收敛子列。
  证明. 设 {{x_n}} 是有界数列...（证明过程）...故命题成立。■

应提取为两个独立条目：
1. {{"item_type": "theorem", "number": "3.1", "title": "Bolzano-Weierstrass", "content": "有界数列必有收敛子列。", "parent_ref": null}}
2. {{"item_type": "proof", "content": "设 {{x_n}} 是有界数列...故命题成立。■", "parent_ref": "theorem:3.1"}}
```

**又一正确示例**：
```
原文：
  例 2.5 计算 $\int_0^1 x^2 dx$。
  解. $\int_0^1 x^2 dx = \frac{{x^3}}{{3}}\big|_0^1 = \frac{{1}}{{3}}$。

应提取为两个独立条目：
1. {{"item_type": "example", "number": "2.5", "content": "计算 $\\int_0^1 x^2 dx$。", "parent_ref": null}}
2. {{"item_type": "solution", "content": "$\\int_0^1 x^2 dx = \\frac{{x^3}}{{3}}\\big|_0^1 = \\frac{{1}}{{3}}$。", "parent_ref": "example:2.5"}}
```

### `parent_ref` 格式

- 格式为 `"<parent_type>:<parent_number>"` 或 `"<parent_type>:<parent_title>"`
- 例如：`"theorem:3.1"`、`"lemma:2.4"`、`"example:5"`、`"exercise:3.2.1"`
- 如果证明/解答的父条目在**同一个 chunk 中**，用其 type 和 number 引用
- 如果找不到明确的父条目（如孤立的证明），设为 `null`
- 知识条目和题目条目的 `parent_ref` 始终为 `null`

### 不应提取的内容
- 章节标题、目录、前言（记录在 structural_context 中）
- 纯过渡性段落（"本章讨论..."、"下面介绍..."）
- 页眉、页脚、页码
- 注记(remark)——除非包含实质性数学结论

### 内容完整性要求
- `content` 必须包含条目的**完整原文**（保留 LaTeX、段落结构）
- 定理的 `content` 只包含**定理陈述**，不包含证明
- 题目的 `content` 只包含**题目描述**，不包含解答
- 证明/解答的 `content` 包含**完整的论证/求解过程**
- 每个条目必须是语义完整的，不要截断

    "chapter_number": "",
    "section_title": "",

  "extracted_items": [

      "number": "3.2.1",

      "content": "设 $f$ 在闭区间 $[a,b]$ 上连续，则 $f$ 在 $[a,b]$ 上一致连续。",
      "parent_ref": null,
      "line_start": 15,
      "line_end": 18
    }},
    {{
      "item_type": "proof",
      "number": null,
      "title": null,
      "content": "由 Borel 有限覆盖定理，对 $\\forall \\varepsilon > 0$...故 $f$ 一致连续。",
      "parent_ref": "theorem:3.2.1",
      "line_start": 19,
      "line_end": 42
    }}
  ]
}}

注意：
- 定理和证明是**两个独立条目**，通过 `parent_ref` 关联
- 题目和解答是**两个独立条目**，通过 `parent_ref` 关联
- `extracted_items` 可以为空数组
- 当 `truncation_line` 为 `"incomplete"` 时，`extracted_items` 应为空数组
