## 任务 A：质量校准
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

对每个条目检查：

1. **文字**：OCR 错字（盐德金→戴德金）、术语（特征植→特征值）
2. **LaTeX**：未闭合 `$...$`、错误符号（`\ln` vs `\in`）
3. **语义**：定义是否完整、定理条件是否齐全、是否被截断
4. **逻辑**：推导是否连贯、条件结论是否匹配
5. **证明/解答**：如有 proof 或 solution，检查论证完整性和正确性

**有效性判断**：纯标题、页码、引言、注记 → `overall_quality = "F"`

**quality 评级**：
- A = 完整准确，无需修改
- B = 小瑕疵（拼写/格式），已修正
- C = 有实质问题但可修复
- D = 严重问题，勉强可用
- F = 无效内容，应丢弃

## 任务 B：多维分类
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

### kp_type 精确判断（知识类条目）

- `definition` — 包含"称为"、"叫做"、"定义为"的定义性陈述
- `theorem` — 有条件+结论的数学命题（"若...则..."）
- `lemma` — 辅助性命题
- `corollary` — 从定理推出的直接结论
- `proposition` — 较弱的命题
- `property` — 性质列举

### question_type 精确判断（题目类条目）

- `proof` — "证明..."、"试证..."、"说明...为什么..."
- `calculation` — "计算..."、"求..."、"求值..."、"化简..."
- `fill_blank` — 含下划线、空格待填
- `choice` — 有 A/B/C/D 选项
- `true_false` — "判断正误"、"是否成立"
- `construction` — "构造..."、"给出一个满足...的..."

### 学科与 Taxonomy

- `subject`: 从内容关键词判断学科（如"群/环/域"→代数, "极限/连续/积分"→分析）
- `taxonomy_path`: `math.algebra.group_theory` 或 `math.analysis.sequences_and_limits` 格式
- 根据**内容实质**选取 taxonomy，不要随意猜测

### Tags 格式（必须遵守）

所有 tag 必须用 `"english:中文"` 双语格式，例如：
- `"group_theory:群论"`, `"normal_subgroup:正规子群"`, `"epsilon_delta:ε-δ语言"`
- `"lagrange_theorem:拉格朗日定理"`, `"integration_by_parts:分部积分"`
- **禁止**纯中文或纯英文 tag
