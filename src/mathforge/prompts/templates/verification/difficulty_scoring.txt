# 评分维度

请对以下 10 个维度分别给出 **1-10 的整数评分**，并严格参照各维度的校准标尺：

### 1. `concept_count` — 涉及的独立知识点数量

| 分值 | 标准 |
|------|------|
| 1-2 | 仅涉及 1 个基础概念 |
| 3-4 | 涉及 2 个知识点 |
| 5-6 | 涉及 3 个知识点，且需要理解其联系 |
| 7-8 | 涉及 4 个以上知识点，跨章节/跨专题 |
| 9-10 | 深度融合多个领域的核心概念 |

### 2. `step_count` — 最短完整解法的步骤数

| 分值 | 标准 |
|------|------|
| 1-2 | 1-2 步即可完成 |
| 3-4 | 3-4 步标准流程 |
| 5-6 | 5-7 步，部分步骤需要思考 |
| 7-8 | 8-12 步，含多个非平凡推导 |
| 9-10 | 12 步以上，或需要多阶段论证 |

### 3. `abstraction_level` — 数学对象的抽象程度

| 分值 | 标准 |
|------|------|
| 1-2 | 具体数值、特定函数 |
| 3-4 | 一般实数、一般多项式 |
| 5-6 | 一般矩阵、一般连续函数、度量空间 |
| 7-8 | 一般赋范空间、一般群/环 |
| 9-10 | 范畴论层次、泛性质 |

### 4. `technique_novelty` — 解法的非标准程度

| 分值 | 标准 |
|------|------|
| 1-2 | 完全标准的教科书流程 |
| 3-4 | 标准方法的简单组合 |
| 5-6 | 需要一个关键 insight 或非显然的切入点 |
| 7-8 | 需要巧妙构造（辅助函数、特殊序列等） |
| 9-10 | 需要原创性方法或非常规思路 |

### 5. `condition_parsing` — 条件解读与转化的难度

| 分值 | 标准 |
|------|------|
| 1-2 | 条件直接明了，无需转化 |
| 3-4 | 需要简单的条件等价转换 |
| 5-6 | 需要将条件翻译为可操作的数学表达 |
| 7-8 | 含隐含条件，需要深层解读 |
| 9-10 | 条件之间存在复杂的隐含关系，需要深入分析才能发现 |

### 6. `computation_load` — 计算量与计算复杂度

| 分值 | 标准 |
|------|------|
| 1 | 几乎无计算 |
| 2-3 | 简单的算术或代数运算 |
| 4-5 | 适中的计算量，需要细心 |
| 6-7 | 繁重的计算，容易出错 |
| 8-10 | 极繁重的计算，或需要精妙的计算技巧 |

### 7. `proof_structure` — 证明/论证的结构复杂度

| 分值 | 标准 |
|------|------|
| 1-2 | 直接推导，线性论证 |
| 3-4 | 需要简单的分步论证 |
| 5-6 | 需要分情况讨论或简单的间接论证 |
| 7-8 | 需要反证法、数学归纳法或嵌套论证 |
| 9-10 | 多层嵌套论证、复杂的构造性证明 |

### 8. `prerequisite_depth` — 所需前置知识的深度

| 分值 | 标准 |
|------|------|
| 1-2 | 仅需基本定义 |
| 3-4 | 需要核心定理（如中值定理、Cayley-Hamilton） |
| 5-6 | 需要重要理论（如一致收敛理论、Jordan 标准形） |
| 7-8 | 需要高级理论或多个深层定理的综合 |
| 9-10 | 需要研究生层次的理论背景 |

### 9. `multi_representation` — 多表示/多视角切换的需求

| 分值 | 标准 |
|------|------|
| 1-2 | 单一表示即可完成 |
| 3-4 | 偶尔需要在两种表示间切换 |
| 5-6 | 核心步骤依赖于两种表示的配合 |
| 7-8 | 需要在三种以上表示间灵活切换 |
| 9-10 | 解法的本质在于多视角的深层统一 |

### 10. `metacognition` — 策略选择与规划的难度

| 分值 | 标准 |
|------|------|
| 1-2 | 解题路径明确，无需策略选择 |
| 3-4 | 有少量路径选择，但正确方向较明显 |
| 5-6 | 需要在多种方法间做出比较和选择 |
| 7-8 | 策略选择是解题的关键环节 |
| 9-10 | 需要高度的元认知能力，策略规划本身就是挑战 |
