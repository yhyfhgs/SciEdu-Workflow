# 3. 输出格式（严格遵守）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

**整个响应必须是且只能是一个合法的 JSON 对象**。第一个字符 `{{`，最后一个字符 `}}`，无 markdown 前后缀、无解释文字。

字段表：

| 字段 | 类型 | 必填 | 约束 |
|---|---|---|---|
| `subject` | string | ✅ | 形如 `english:中文`（见 §3.1）；同一二级学科整库统一 |
| `taxonomy_path` | string | ✅ | **精确出现**在 §6 Taxonomy 树中；**必须以 `{discipline_taxonomy_root}.` 开头**或等于 `{discipline_taxonomy_root}` |
| `tags` | string[] | ✅ | 至少 2 段；每段 `english:中文`；**`tags[0]` 必须等于 `{discipline_example_tag_root}`** |
| `difficulty` | int | ✅ | 1-10，见 §4 档位 |
| `question_type` | string\|null | ✅ | `item.category=="question"` → 非空且属 `{discipline_question_type_hints}`；`knowledge` → `null` |
| `methods` | string[] | ✅ | 可空数组；每段同 tags 格式 |

**不得输出** schema 外字段（`quality_grade` / `comments` 等）。
**不得修改** item 的 content / proof / solution。

## 3.1 段格式（tags / methods / subject 每段）

严格匹配正则 `^[a-z][a-z0-9_]*:[^\s:]+$`：
- **english 部分**：小写字母开头，仅 `a-z 0-9 _`（如 `group_theory` / `real_analysis`）
- **冒号**：半角 ASCII `:`（U+003A）；**禁用**全角 `：`（U+FF1A）
- **中文部分**：非空，不含空白、冒号、斜杠

**非法示例**：`"Math:数学"`（大写） / `"math: 数学"`（含空格） / `"数学"`（无冒号） / `"math:数:学"`（多冒号） / `"math：数学"`（全角冒号）


# 5. 注意要点
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

**A. 学科根一票否决**（最易犯错）：
- `tags[0]` **必须**等于 `{discipline_example_tag_root}`（即使条目看起来跨学科，本次标注的所属学科已固定为 `{discipline_name}`）
- `taxonomy_path` **必须**以 `{discipline_taxonomy_root}.` 开头或等于 `{discipline_taxonomy_root}`
- 违反将导致重试

**A+. tags[1] 必须是学科主分支**（层级完整性）：
- `tags[1]` 的 english 部分**必须**属于学科主分支白名单（如 math 的 `algebra` / `analysis` / `abstract_algebra` / `linear_algebra` / `number_theory` / `combinatorics` / ...）
- **不得**直接从 `tags[0]` 跳到二级/三级细分概念（例如"math:数学" → "group_theory:群论"**违规**，正确应为"math:数学" → "abstract_algebra:抽象代数" → "group_theory:群论"）
- 违反将导致重试

**B. 复用优先，避免同义异名**（tag_tree 通用性）：
- `tag_tree` 已有 `group_theory:群论` → 遇到群论相关条目**不要**新建 `groups:群` 或 `group:群论`
- `tag_tree` 已有 `epsilon_delta:ε-δ语言` → **不要**新建 `eps_delta:ε-δ方法`
- 确属全新主题时才新建（审慎）

**C. Taxonomy 必须选已有路径**：
- `taxonomy_path` 是闭集，只能从 §6 给定的 Taxonomy 树中**精确**选择
- **不得**自创路径段

**D. subject 整库稳定**：
- 同一二级学科（如"实分析"）在整个知识库里必须用**完全相同**的 `english:中文`
- 变体如 `real_analysis:实分析` vs `analysis_real:实数分析` → 违反

**E. question_type 与 category 一致**：
- `item.category == "question"` → `question_type` 非空且属允许列表
- `item.category == "knowledge"` → `question_type = null`

**F. methods 复用原则**：
- 方法名与 tags 同格式；同一方法整库统一
- 数量 0-5 段常见；没有明显方法则 `[]`

**G. 段数不是重点**：tags 常见 3-6 段，methods 0-5 段；段数不是强约束——**重点是复用与一致**
