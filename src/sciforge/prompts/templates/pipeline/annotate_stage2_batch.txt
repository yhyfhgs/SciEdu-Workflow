# 3. 输出格式（严格遵守）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

**整个响应必须是且只能是一个合法的 JSON 对象**，形如 `{{"annotations":[ ... ]}}`。第一个字符 `{{`，最后一个字符 `}}`，无 markdown、无解释文字。

**`annotations` 数组长度必须严格等于输入 items 数量，且顺序一一对应**（第 i 个标注对应第 i 条 item）。不得增删、不得换序、不得合并。

每个标注元素的字段表：

| 字段 | 类型 | 必填 | 约束 |
|---|---|---|---|
| `subject` | string | ✅ | 形如 `english:中文`（见 §3.1）；同一二级学科整库统一 |
| `taxonomy_path` | string | ✅ | **精确出现**在 §6 Taxonomy 树中；**必须以 `{discipline_taxonomy_root}.` 开头**或等于 `{discipline_taxonomy_root}` |
| `tags` | string[] | ✅ | 至少 2 段；每段 `english:中文`；**`tags[0]` 必须等于 `{discipline_example_tag_root}`** |
| `difficulty` | int | ✅ | 1-10，见 §4 档位 |
| `question_type` | string\|null | ✅ | 该 item `category=="question"` → 非空且属 `{discipline_question_type_hints}`；`knowledge` → `null` |
| `methods` | string[] | ✅ | 可空数组；每段同 tags 格式 |

**不得输出** schema 外字段。**不得修改** item 的 content / proof / solution。

## 3.1 段格式（tags / methods / subject 每段）

严格匹配正则 `^[a-z][a-z0-9_]*:[^\s:]+$`：
- **english 部分**：小写字母开头，仅 `a-z 0-9 _`（如 `group_theory` / `real_analysis`）
- **冒号**：半角 ASCII `:`（U+003A）；**禁用**全角 `：`（U+FF1A）
- **中文部分**：非空，不含空白、冒号、斜杠

## 3.2 输出示例（2 条 item 的情形）

```
{{"annotations":[{{"subject":"{discipline_example_subject}","taxonomy_path":"{discipline_example_taxonomy}","tags":{discipline_tag_example},"difficulty":6,"question_type":null,"methods":[]}},{{"subject":"{discipline_example_subject}","taxonomy_path":"{discipline_example_taxonomy}","tags":{discipline_tag_example},"difficulty":4,"question_type":null,"methods":[]}}]}}
```

# 4. difficulty 档位

# 5. 注意要点
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

**A. 学科根一票否决**（最易犯错）：每条标注 `tags[0]` **必须**等于 `{discipline_example_tag_root}`；`taxonomy_path` **必须**以 `{discipline_taxonomy_root}.` 开头或等于 `{discipline_taxonomy_root}`。违反将导致整批重试。

**A+. tags[1] 必须是学科主分支**：不得直接从 `tags[0]` 跳到二级/三级细分概念（如"math:数学"→"group_theory:群论"违规，应为"math:数学"→"abstract_algebra:抽象代数"→"group_theory:群论"）。

**B. 复用优先，避免同义异名**：已有 `group_theory:群论` → 不要新建 `groups:群`。

**C. Taxonomy 必须选已有路径**：`taxonomy_path` 是闭集，只能从 §6 精确选择，不得自创。

**D. subject 整库稳定**：同一二级学科必须用完全相同的 `english:中文`。

**E. question_type 与 category 一致**：`question` → 非空且属允许列表；`knowledge` → `null`。

**F. 数量**：tags 常见 3-6 段，methods 0-5 段；段数不是强约束——重点是复用与一致。
