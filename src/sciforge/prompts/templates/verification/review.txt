{question_latex}

# 审核清单

1. **条件自洽性**：所有条件相互兼容？有无逻辑矛盾？
2. **结论正确性**（证明题）：给定条件下结论为真命题？能否构造反例？建议用特殊情形验证
3. **答案存在性**（计算题）：所求量确定且唯一？有无使计算无意义的边界情况（除零、对数真数为负等）？
4. **条件充分性**：条件足以推出结论？有无遗漏必要条件（可微性、完备性等"约定俗成"条件）？
5. **非退化性**：有无平凡退化使题目无意义（所求量恒为零、集合为空等）？

# 难度评分维度（仅当 verdict="PASS" 时填写，FAIL 时可省略）

每项 1-10 整数：

- **concept_count**：独立知识点数量（1-2 单一基础 / 3-6 2-3 个 / 7-8 跨章节 / 9-10 深度融合）
- **step_count**：最短完整解法步骤数（1-2 一步 / 3-6 标准流程 / 7-8 多非平凡推导 / 9-10 多阶段论证）
- **abstraction_level**：数学对象抽象程度（1-2 具体数值 / 3-6 一般函数/矩阵 / 7-8 赋范空间/群环 / 9-10 范畴论）
- **technique_novelty**：解法非标准程度（1-2 标准流程 / 3-6 方法组合 / 7-8 需巧妙构造 / 9-10 原创性方法）
- **condition_parsing**：条件解读转化难度（1-2 直接 / 3-6 简单等价 / 7-8 隐含条件 / 9-10 深层分析）
- **computation_load**：计算量与复杂度（1-3 简单算术 / 4-7 适中到繁重 / 8-10 精妙技巧）
- **proof_structure**：证明/论证结构复杂度（1-2 线性推导 / 3-6 分步/分情况 / 7-8 反证/归纳 / 9-10 多层嵌套）
- **prerequisite_depth**：前置知识深度（1-2 基本定义 / 3-6 核心定理 / 7-8 高级理论 / 9-10 研究生层次）
- **multi_representation**：多表示/多视角切换（1-2 单一 / 3-6 两种 / 7-8 三种+ / 9-10 多视角深层统一）
- **metacognition**：策略选择与规划难度（1-2 路径明确 / 3-6 需选择 / 7-8 策略关键 / 9-10 元认知挑战）
