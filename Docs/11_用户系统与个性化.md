# 用户系统与个性化推荐

> 当前 MVP 已实现：`SaasStore` 的 tenant/user/API key/usage/task/user_behavior、用户名密码登录、
> 自定义 HMAC 签名 bearer access token、scope/quota、tenant 内容隔离与无 LLM RecommendEngine。
> 本文第 2 节起的大部分表结构仍是完整学习平台蓝图，不是当前物理 schema；当前表以
> `src/sciforge/storage/saas.py` 为准，API 以 `Docs/08_FastAPI服务层.md` 为准。

## 1. 定位

用户认证、多学科学习记录、错题分析、能力画像（按学科+学段维度）、个性化推荐。用户可关注多个学科，系统按学科独立追踪学习进度。

## 2. 用户系统

### 2.1 数据库表（SQLite）

```sql
CREATE TABLE users (
    id              TEXT PRIMARY KEY,
    username        TEXT UNIQUE NOT NULL,
    email           TEXT UNIQUE NOT NULL,
    password_hash   TEXT NOT NULL,
    display_name    TEXT,
    role            TEXT DEFAULT 'student',  -- student | teacher | admin
    created_at      TEXT DEFAULT (datetime('now')),
    updated_at      TEXT DEFAULT (datetime('now'))
);

CREATE TABLE user_preferences (
    id              TEXT PRIMARY KEY,
    user_id         TEXT REFERENCES users(id) ON DELETE CASCADE UNIQUE,
    subjects        TEXT DEFAULT '[]',          -- JSON array
    difficulty_range TEXT DEFAULT '{"min":1,"max":5}',  -- JSON object
    latex_style     TEXT DEFAULT 'default',
    language        TEXT DEFAULT 'zh-CN'
);
```

### 2.2 认证方案

- 当前：自定义 HMAC-SHA256 签名 bearer access token（非 JWT），含 exp/user/tenant；无 refresh/
  吊销表；API key 仅存 SHA-256；
- 当前密码摘要由 `api/security.py` 实现并安全比较；
- 蓝图：refresh rotation、撤销、第三方 identity 与更细角色权限尚未实现。

## 3. 学习记录系统

### 3.1 做题记录表

```sql
CREATE TABLE user_question_records (
    id              TEXT PRIMARY KEY,
    user_id         TEXT REFERENCES users(id) ON DELETE CASCADE,
    question_id     TEXT REFERENCES questions(id) ON DELETE CASCADE,
    status          TEXT NOT NULL,   -- attempted | correct | wrong | skipped
    user_answer     TEXT,
    time_spent_sec  INTEGER,
    error_type      TEXT,            -- concept | calculation | logic | omission
    error_analysis  TEXT,            -- AI 生成的错因分析
    attempted_at    TEXT DEFAULT (datetime('now'))
);
```

### 3.2 错题分析

AI 错题分析器接收题目、用户答案和正确解答，输出:
- `error_type`: concept / calculation / logic / omission
- `error_analysis`: 详细错因说明
- `weak_knowledge_points`: 关联薄弱知识点
- `suggestions`: 改进建议

### 3.3 错因分类

| 错因 | 说明 | 示例 |
|------|------|------|
| concept | 概念理解错误 | 混淆一致连续和连续 |
| calculation | 计算错误 | 行列式展开符号错误 |
| logic | 逻辑推理错误 | 充分/必要条件搞反 |
| omission | 遗漏/审题不清 | 遗漏条件导致结论不成立 |

## 4. 能力画像

### 4.1 用户画像模型

```python
class UserProfile(BaseModel):
    user_id: str
    subject_profiles: dict[str, SubjectProfile]  # 按学科维护独立画像
    overall_level: float                 # 综合能力水平
    active_subjects: list[str]           # 用户关注的学科列表
    completed_ids: set[str]              # 已做题 ID（全局）
    recent_wrong_ids: list[str]          # 最近错题

class SubjectProfile(BaseModel):
    """单学科能力画像"""
    subject_domain: str                  # 学科大类
    education_level: str                 # 教育阶段
    topic_accuracy: dict[str, float]     # 各专题正确率
    topic_volume: dict[str, int]         # 各专题练习量
    estimated_level: float               # 该学科能力水平
    weak_topics: list[str]               # 正确率 < 60% 的专题
    radar_data: dict[str, float]         # 雷达图数据（该学科各维度）
```

### 4.2 雷达图维度

每个维度 = 正确率(40%) + 难度水平(30%) + 练习量(30%)。

雷达图按学科独立生成，维度为该学科的核心专题。例如:
- **数学分析**: 极限、连续性、微分、积分、级数
- **高等代数**: 线性空间、线性映射、特征值、矩阵分解
- **力学**: 牛顿力学、能量守恒、动量、刚体力学

## 5. Recommend Agent

### 5.1 推荐模式

| 模式 | 说明 | 策略 |
|------|------|------|
| `weakness` | 薄弱点专项 | 选正确率 < 60% 的专题，难度 = 当前水平 ± 1（按学科独立） |
| `advance` | 进阶挑战 | 当前水平 +1-2 难度，偏向未涉及专题（可跨学科推荐关联内容） |
| `review` | 错题变式 | 取近 20 道错题，生成 A1 变式 |
| `comprehensive` | 综合推荐 | 40% 薄弱 + 30% 进阶 + 30% 复习 |
| `cross_subject` | 跨学科关联 | 基于知识点关联推荐相关学科内容（如学完微积分推荐力学应用） |

### 5.2 附加能力

薄弱点明确时可自动生成针对性讲义（委托 DocAssembly Agent）。
