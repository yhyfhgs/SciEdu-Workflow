## 2. pyproject.toml 关键配置

```toml

    "pydantic>=2.0",

```

构建系统使用 hatchling，包路径为 `src/mathforge`。

## 3. 编码规范

| 规则 | 说明 |
|------|------|
| Python 版本 | 3.11+（`match`、`X \| Y` 联合类型、`StrEnum`） |
| 模型定义 | 统一 Pydantic v2 BaseModel（不用 dataclass） |
| 类型注解 | 所有函数签名必须有 |
| 文档字符串 | Google 风格 |
| 行宽 | 100 字符 |
| 格式化 | ruff format |
| 导入排序 | ruff（isort 兼容） |
| 命名 | 文件 snake_case, 类 PascalCase, 常量 UPPER_SNAKE |

## 5. 配置管理

`AppConfig` 使用 pydantic-settings，支持环境变量（`MATHFORGE_` 前缀）和 `.env` 文件：

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `data_dir` | `"data"` | 生成数据目录 |
| `raw_data_dir` | `"Raw Data"` | 原始数据目录 |
| `llm_provider` | `"anthropic"` | LLM 提供者 |
| `llm_model` | `"claude-sonnet-4-20250514"` | 模型名称 |
| `llm_temperature` | `0.7` | 默认温度 |
| `llm_max_tokens` | `4096` | 默认 max_tokens |
| `max_concurrent_llm_calls` | `3` | 并发 LLM 调用数 |
| `generation_max_rounds` | `3` | 生成最大轮数 |
| `pdf_batch_size` | `20` | PDF 每批页数 |
| `log_level` | `"INFO"` | 日志级别 |
| `log_format` | `"console"` | console / json |

---

## 6. 日志系统

使用 structlog 结构化日志:
- **console 模式**（开发）: 带颜色的可读格式
- **json 模式**（批量/生产）: JSON 行格式

日志级别使用指南: DEBUG（LLM prompt 内容）、INFO（操作完成）、WARNING（可恢复问题）、ERROR（操作失败）。

## 7. 测试策略

| 层级 | 内容 | LLM 调用 |
|------|------|----------|
| 单元测试 | 模型验证、解析器、Prompt 构建 | 无 |
| 集成测试 | Pipeline + mock LLM、存储读写 | Mock |
| 快照测试 | Pipeline 输出 vs golden file | 无 |
| Pipeline Agent 测试 | BlockSplitter/ItemProcessor 各格式正确性 | Mock |
| 人工验证 | 生成题目的数学正确性 | 真实 |

测试框架: pytest + pytest-asyncio, 代码检查: ruff, 类型检查: mypy --strict。

## 8. 实现顺序

```
第 1 批（无依赖）: models.py, settings.py, logging.py, prompts/
第 2 批（LLM 层）: llm/config.py, parser.py, backends/*.py, client.py
第 3 批（存储）: storage/
第 4 批（Pipeline 核心）: pipeline/orchestrator.py, block_splitter.py, meta_extractor.py
第 5 批（Pipeline 处理）: pipeline/agents/item_processor.py, item_unifier.py, entity_builder.py, relation_builder.py
第 6 批（格式转换器）: pipeline/pdf_processor.py, docx_processor.py, csv_processor.py, ocr_repair.py
第 7 批（生成引擎）: core/retriever.py, generator.py, solver.py, verifier.py, annotator.py, engine.py
第 8 批（CLI）: cli/*.py
```
