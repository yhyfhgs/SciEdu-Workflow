# TeX 解析与题库构建

> 版本: v1.2 | 日期: 2026-03-31

> 本文档描述 TeX 文件的 **Python-first 快速通道**，是 MVP 阶段大学数学题库构建的核心组件。对于未知格式文件，请使用通用 Pipeline（见 `01_数据处理Pipeline.md`）。
>
> TeX 解析器是学科无关的——解析逻辑基于 LaTeX 环境结构，而非数学特定内容。未来物理/CS 等学科的 TeX 文件可复用同一解析器，仅需调整 ContentTagger 的学科 prompt。

## 1. 目标

- 解析 `Raw Data/新领军真题整理/` 下全部 23 个 TeX 文件（大学数学竞赛真题）
- 提取 ~150-200 道独立题目及其解答
- 按考试类型分类并分配难度等级
- 自动标注 `subject_domain=math`, `education_level=undergraduate`
- 输出结构化 JSON + 干净的 LaTeX

## 3. 解析策略

### 3.1 文件分类

从文件名提取元数据：`YYYY.M.tex` → 零试, `YYYY一试.tex` → 一试, `YYYY女子.tex` → 女子。

### 3.2 题目提取

全部文件使用一致的 LaTeX 结构：`\begin{problem}[第N题]...\end{problem}` + `\begin{solution}...\end{solution}`。

**边界情况处理**:

| 情况 | 处理方式 |
|------|----------|
| `\begin{solution}[解析]` 带可选参数 | 可选匹配 |
| `\begin{boxedsolution}` tcolorbox | 增加正则 |
| `\begin{exercise}[变式N]` | 独立提取，标记为变式 |
| 无 solution 的 problem | `has_solution=False` |
| `202510new.tex` 特殊格式 | 单独适配 |

### 3.3 LaTeX 清理

- 展开自定义宏（`\bbR` → `\mathbb{R}` 等）
- 标准化空白符
- 去除格式命令（`\noindent`, `\medskip` 等）
- 验证括号匹配

### 3.4 难度分配

| 考试类型 | 题数 | 难度范围 | 特征 |
|----------|------|----------|------|
| 零试 | 10-15 | 3-6 | 计算+短证明，题目渐难 |
| 一试 | 6-8 | 5-8 | 深度证明，多步推理 |
| 女子 | 6-8 | 5-8 | 理论证明，概念深度 |

零试位置映射: 第 1-4 题 → 3-4, 第 5-8 题 → 4-5, 第 9-12 题 → 5-6, 第 13+ → 6+。

### 3.5 自动标签

由通用 Pipeline 的 **ContentTagger Agent** 统一处理（见 `01_数据处理Pipeline.md` §3.4），标签维度: 科目、专题、方法、题型。
