# 文档生成系统

> 版本: v2.0 | 日期: 2026-03-31 | 阶段: Phase 6 (Post-MVP)
>
> ⚠️ **部分实现**：MVP 阶段只有 DocAssembly-lite（markdown 输出），见
> `src/sciforge/agents/doc_agent.py`。本文档描述的 LaTeX 编译 / Jinja2 模板 / PDF 输出为 Post-MVP。

## 1. 定位

自动化组装多学科试卷、讲义、练习册，从题库/知识库中按学科+学段智能选取内容，通过 Jinja2 模板填充 LaTeX，编译为 PDF。支持数学、物理等多学科的文档模板。

---

## 2. 文档类型

| 类型 | 输入 | 输出 |
|------|------|------|
| **试卷 (exam)** | 科目+专题+难度+题数+时长 | 题目卷 PDF + 答案卷 PDF |
| **讲义 (handout)** | 专题+深度+例题数+习题数 | 教学讲义 PDF |
| **练习册 (worksheet)** | 专题+难度范围+题数 | 练习题集 PDF |
| **小测 (quiz)** | 知识点+5-10题+15分钟 | 随堂测试 PDF |

    1. 难度分布匹配目标 (如: 容易30%, 中等40%, 困难30%)
    2. 知识点覆盖尽可能广
    3. 题型分布匹配目标
    4. 同一知识点最多出现在 2 道题中
    5. 总分 = 指定分数
    6. 预估完成时间 ≈ 指定时间

    async def assemble(self, params: ExamParams) -> list[ScoredQuestion]:
        # Step 1: 候选池 (从题库+新生成题中筛选)
        pool = await self._build_candidate_pool(params)

        # Step 2: 贪心初始解
        selected = self._greedy_select(pool, params)

        # Step 3: 局部搜索优化 (swap-based, max 100 iterations)
        optimized = self._local_search(selected, pool, params, max_iter=100)

## 6. LaTeX 编译服务

```python
# backend/core/latex_engine.py

class LatexEngine:
    """XeLaTeX 编译服务"""

    def __init__(self, template_dir: Path, output_dir: Path):
        self.template_dir = template_dir
        self.output_dir = output_dir

    async def compile(self, latex_source: str, filename: str = "output") -> Path:
        work_dir = self.output_dir / filename
        work_dir.mkdir(parents=True, exist_ok=True)

        tex_path = work_dir / f"{filename}.tex"
        tex_path.write_text(latex_source)

        # 复制模板依赖
        for base_file in (self.template_dir / "base").iterdir():
            shutil.copy(base_file, work_dir)

        # 编译 (两次以处理交叉引用)
        for _ in range(2):
            proc = await asyncio.create_subprocess_exec(
                "xelatex", "-interaction=nonstopmode", str(tex_path),
                cwd=str(work_dir),
                stdout=asyncio.subprocess.PIPE,
                stderr=asyncio.subprocess.PIPE,
            )
            stdout, stderr = await proc.communicate()
            if proc.returncode != 0:
                raise LatexCompileError(stderr.decode())

        return work_dir / f"{filename}.pdf"
```

## 7. Jinja2 模板引擎

```python
# backend/core/template_engine.py

from jinja2 import Environment, FileSystemLoader

class TemplateEngine:
    def __init__(self, template_dir: Path):
        self.env = Environment(
            loader=FileSystemLoader(str(template_dir)),
            block_start_string='<%',       # 避免与 LaTeX 的 {} 冲突
            block_end_string='%>',
            variable_start_string='<<',
            variable_end_string='>>',
            comment_start_string='<#',
            comment_end_string='#>',
        )

    def render(self, template_name: str, context: dict) -> str:
        template = self.env.get_template(template_name)
        return template.render(**context)
```

> 注: 由于 LaTeX 大量使用 `{}`，Jinja2 使用自定义分隔符 `<< >>` 和 `<% %>`。
