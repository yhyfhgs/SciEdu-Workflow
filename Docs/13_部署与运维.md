# 部署与运维

> 当前已实现单机 `uv run sciforge serve`（FastAPI + `/app/` + 四类 SQLite）以及 CLI。
> 本文的 Next.js/Vercel、Docker Compose、K8s、集中监控和成本表仍是部署蓝图，不代表仓库已有
> 对应 manifest。当前运行契约见 `Docs/08_FastAPI服务层.md`。

## 1. 部署架构

```
              ┌──── CDN (Cloudflare) ────┐
              │                          │
              ▼                          ▼
     ┌──────────────┐          ┌────────────────┐
     │   Next.js    │          │ Static Assets  │
     │   (Vercel)   │          │                │
     └──────┬───────┘          └────────────────┘
            │ API calls
            ▼
  ┌──── Nginx (反向代理) ────┐
  │                          │
  ▼                          ▼
┌──────────┐           ┌───────────┐
│ FastAPI   │           │ TeX Live  │
│ (uvicorn) │           │ (PDF编译)  │
└─────┬─────┘           └───────────┘
      │
      ▼
┌───────────────┐
│ SQLite +      │
│ sqlite-vec    │
│ (嵌入式数据库) │
└───────────────┘
```

优势：无需 PostgreSQL、Redis、MinIO 等外部服务，大幅简化运维。

---

## 2. Docker Compose (开发环境)

仅需两个服务:

| 服务 | 说明 |
|------|------|
| `api` | FastAPI 后端（含嵌入式 SQLite） |
| `frontend` | Next.js 前端 |

SQLite 数据库文件通过 Docker volume 挂载持久化。TeX Live 安装在 api 容器中（用于 PDF 编译）。

---

## 3. 生产部署方案

| 组件 | 方案 | 说明 |
|------|------|------|
| 前端 | Vercel | 零运维，自动 CI/CD |
| API | 单机 Docker + Nginx | 或轻量 VPS |
| 数据库 | SQLite 文件（volume 挂载） | 嵌入式，无需托管服务 |
| 文件存储 | 本地文件系统 / S3（可选） | PDF 原文件存储 |
| CDN | Cloudflare | 静态资源加速 |

---

## 4. 环境变量

| 变量 | 说明 |
|------|------|
| `SCIFORGE_DB_PATH` | SQLite 数据库路径（默认 `data/sciforge.db`） |
| `ANTHROPIC_API_KEY` | LLM API Key |
| `SCIFORGE_TOKEN_SECRET` | 自定义 HMAC bearer token 签名密钥（token 非 JWT） |
| `SCIFORGE_JWT_SECRET` | 向后兼容的旧变量名；新部署优先使用 `SCIFORGE_TOKEN_SECRET` |
| `SCIFORGE_LOG_LEVEL` | 日志级别 |
| `SCIFORGE_LOG_FORMAT` | 日志格式（console/json） |

---

## 5. 数据库迁移

内容库使用 `PRAGMA user_version` 与 `sqlite_backend._MIGRATIONS`，当前 v14；v8–v13 启动时逐步
迁移，更旧、未来或不完整 schema fail closed。conversation/runtime 使用各自 schema v1 元数据
表，SaaS schema 独立。部署升级前必须对四个 DB 分别做一致性备份，不能只复制主内容库。

## 7. 成本估算

| 项目 | 月费 (USD) |
|------|------------|
| LLM API (Claude) | $50-150 |
| Embedding API | $10-30 |
| 服务器 (2C4G VPS) | $15-30 |
| 域名 + CDN | $0-10 |
| **合计** | **$75-220/月** |

无数据库托管费（SQLite 嵌入式）、无文件存储费（本地文件系统）。

## 8. 备份策略

| 数据 | 频率 | 方式 |
|------|------|------|
| SQLite 数据库 | 每日 | `sqlite3 .backup` 命令或文件复制 |
| 上传的 PDF/文件 | 每周 | rsync 或 S3 同步 |
| 配置文件 | 持续 | Git 版本控制 |
